# Interpreting the CARNIVAL Output in a Biological Context

## Abstract

"CARNIVAL (CAusal Reasoning for Network identification using Integer VALue programming) is a tool designed to infer upstream causality in molecular networks through integer linear programming (ILP). The main application of CARNIVAL is the identification of important signaling proteins in perturbed molecular networks e.g. in cancer cells. CARNIVAL’s output is often a collection of possible subnetworks that explain the perturbation signal, but it is not fully understood how to interpret the result of the tool. In this thesis, I use small contained synthetic networks and easily understandable examples to examine how CARNIVAL’s output is influenced by the network’s architecture, a real biological network to show how CARNIVAL deals with specific protein interactions and manual changes to CARNIVAL to model these such interactions more accurately. I show how CARNIVAL suffers from its very simple network model and propose to add a function for the user to change to the integer linear programming problem formulation to find more accurate results."
